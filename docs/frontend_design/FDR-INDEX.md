## What are FDRs?
Frontend Decision Records (FDRs) govern the client-side architecture. This includes framework selection, API integration patterns, state management, styling, rendering strategies, streaming data approaches, form management, and telemetry.

FDRs are added iteratively as new frontend challenges surface.
